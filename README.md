# Nightmare Horde

Nightmare Horde is a Minecraft plugin that adds a variety of horror creatures to your game. This plugin includes iconic horror characters such as Jason, Freddy Krueger, SCP-173, SCP-096, SCP-049, Freedy, Fazbear, Baldi, Granny, Siren, Predator, Xenomorph, Pyramid Head, Springtrap, Jeff, Slenderman, Bendy, Chucky, Leatherface, Michael Myers, Pinhead, Ghostface, and Sonic. Each creature has unique behaviors and attributes to enhance your horror gaming experience.

## Install

1. Download the plugin JAR file from the [GitHub repository](https://github.com/EnderDevelopment/NightmareHorde).
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart your Minecraft server to load the plugin.

## Use

1. Ensure you have the necessary permissions to use the plugin commands.
2. Use the command `/spawncreature <creature>` to spawn a horror creature. Replace `<creature>` with the name of the creature you want to spawn (e.g., `/spawncreature jason`).
